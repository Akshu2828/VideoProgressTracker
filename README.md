# 🎥 Video Progress Tracker

A full-stack application that tracks users' video-watching progress, resumes playback from the last watched point, and saves progress to a Database.

## 🌐 Live Demo

🔗 [View Deployed App on Vercel](https://video-progress-tracker-chi.vercel.app/)


## 🚀 Getting Started

### 1. Clone the Repository

##### git clone https://github.com/Akshu2828/VideoProgressTracker.git
##### cd video-progress-tracker

### 2. Backend Setup
##### cd backend
##### npm install
##### npm run dev 

### 3. Frontend Setup
##### cd frontend
##### npm install
##### npm run dev

### Now you're ready to go 🚀
